:::caution[Experimental]
Acropolis is experimental. It is an opt-in builder on [Olimpia](https://olimpia.dev) and passes the [compatibility suites](/compatibility), but its CLI, output and defaults can still change between releases. Pin a version and read the [changelog](https://github.com/olimpiacloud/acropolis/blob/main/CHANGELOG.md) before upgrading.
:::

Acropolis takes an app's source code and returns an OCI image ready to run. It detects the language and framework, downloads verified toolchains and dependencies, compiles, and assembles the image. It is the builder behind [Olimpia](https://olimpia.dev).

```bash
acropolis build ./my-app -t registry.example.com/team/my-app:latest
acropolis build ./my-app --oci image.tar --info info.json
acropolis plan ./my-app
```
